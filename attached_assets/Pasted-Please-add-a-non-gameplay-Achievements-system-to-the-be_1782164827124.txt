Please add a non-gameplay “Achievements” system to the beach volleyball manager game.

Important:
- Achievements must NOT affect gameplay, finances, player ratings, training, match results, youth development, scouting, or transfers.
- They are only long-term goals for the user to complete.
- Add a new Achievements page/screen.
- Achievements should show: achievement name, description, status locked/unlocked, date/season unlocked if available.
- Once unlocked, they stay unlocked permanently.
- Achievements should persist/save with the manager career save data.

Implementation:
- Create a central achievement definitions array/object so achievements are easy to add later.
- Create a function like checkAchievements(gameState) that runs after relevant events:
  - match completed
  - tournament completed
  - season completed
  - youth signed
  - youth promoted
  - player rating improved
  - club balance changes
  - manager changes town/continent
  - Olympic/world/continental competition completed
- Avoid checking achievements every frame/render if possible.
- Unlock achievements only once.
- Add a small notification/toast when an achievement unlocks.
- Add filtering or grouping if simple: Career, Finance, Youth, Competition, Legacy.
- If exact data fields do not already exist, use the closest existing fields in the current gameState. Do not break existing systems.
