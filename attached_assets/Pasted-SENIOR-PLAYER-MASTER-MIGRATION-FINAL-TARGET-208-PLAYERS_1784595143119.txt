STAGE 2 — STANDARDISE ALL 208 IMAGE FILES

Use one canonical senior-player image directory.

Use the existing directory that currently holds the 96 player_senior_*.webp files unless the application already defines another canonical senior-player directory.

Every senior-player image must use this naming convention:

player_senior_<country_slug>_<two-digit-number>.webp

Examples:

player_senior_kenya_01.webp
player_senior_puerto_rico_03.webp
player_senior_dominican_republic_02.webp
player_senior_cook_islands_01.webp

FILENAME RULES

1. Use lowercase only.
2. Use underscores instead of spaces or hyphens.
3. Use the player’s canonical country of origin—not their club.
4. Use a two-digit sequence: 01, 02, 03 and so on.
5. Every filename must be unique.
6. Country numbering must be deterministic and stable on future runs.
7. Use proper country slugs, including:
   - puerto_rico, not peurto_rico
   - dominican_republic
   - papua_new_guinea
   - cook_islands
   - south_africa
   - new_zealand
8. Correct the three newly uploaded Puerto Rico filenames currently misspelled with `peurto_rico`.
9. Do not merely change an extension. If an older source image is PNG or JPEG, properly convert the actual file to WebP at high quality without cropping, resizing, redesigning or degrading it.
10. Preserve the original resolution and aspect ratio wherever possible.
